# Cadastro de Alunos

Sistema simples de cadastro de alunos, feito em Python, usando Programação Orientada a Objetos e banco de dados.

O programa roda no terminal e permite:

- Adicionar um aluno (nome e nota)
- Buscar a nota de um aluno pelo nome
- Alterar a nota de um aluno
- Apagar um aluno do banco
- Mostrar se o aluno está aprovado ou reprovado, com base na nota

 Tecnologias usadas

- Python
- SQLite
- Programação Orientada a Objetos
